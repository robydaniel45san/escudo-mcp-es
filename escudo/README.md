# escudo

Capa Escudo ES: normalización de texto, reglas bilingües de intención e informe del hallazgo.

`informe.py` no vuelve a detectar. Redacta lo que las reglas ya encontraron, cita la frase y rechaza un archivo, una URL o una IP que no esté en la descripción. Varias alertas sobre la misma descripción cuentan como un solo incidente.
